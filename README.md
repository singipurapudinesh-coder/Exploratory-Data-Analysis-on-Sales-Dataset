# 📊 Sales Data Analysis and Business Insights Using Python

## Minor Project – Data Science Domain

### 📌 Project Overview

**Sales Data Analysis and Business Insights Using Python** is an Exploratory Data Analysis (EDA) project developed to analyze sales transaction data and identify meaningful business trends and patterns.

The project uses Python-based data analysis and visualization techniques to examine product performance, revenue distribution, sales volume, and monthly sales trends. The analysis helps transform raw sales data into useful business insights that can support decision-making.

---

## 🎯 Objective

The main objectives of this project are:

* Load and understand a sales dataset.
* Identify and handle missing values.
* Perform basic data cleaning.
* Remove duplicate and invalid records.
* Calculate total and average sales.
* Analyze product-wise revenue and quantity.
* Analyze monthly sales trends.
* Generate meaningful visualizations.
* Identify important business insights from the data.

---

## 🛠️ Technologies Used

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Interactive data analysis

## 📊 Dataset

The project uses a sales dataset containing the following important fields:

| Column     | Description                            |
| ---------- | -------------------------------------- |
| `Date`     | Date of the sales transaction          |
| `Product`  | Name of the product                    |
| `Quantity` | Number of units sold                   |
| `Revenue`  | Revenue generated from the transaction |

---

## 🔄 Data Processing

The following data preprocessing steps are performed:

1. Load the raw CSV dataset.
2. Inspect the dataset structure.
3. Check missing values.
4. Check duplicate records.
5. Convert the `Date` column into datetime format.
6. Convert `Quantity` and `Revenue` into numeric values.
7. Handle missing values.
8. Remove duplicate records.
9. Remove invalid date records.
10. Save the cleaned dataset.

---

## 📈 Analysis Performed

### Overall Sales Analysis

The project calculates:

* Total revenue
* Average revenue per transaction
* Total quantity sold
* Average quantity per transaction

### Product-Wise Analysis

The project analyzes:

* Total quantity sold by product
* Total revenue by product
* Average revenue by product
* Highest-revenue product
* Highest-quantity product
* Lowest-revenue product

### Monthly Sales Analysis

Monthly revenue is calculated to identify:

* Highest-revenue month
* Lowest-revenue month
* Monthly sales variations
* Difference between highest and lowest monthly revenue

### Correlation Analysis

The project also examines the relationship between:

* Quantity sold
* Revenue generated

---

## 📊 Visualizations

The project generates the following visualizations:

### 1. Revenue by Product

A bar chart is used to compare the total revenue generated by different products.

### 2. Monthly Revenue Trend

A line chart is used to identify changes in revenue over time.

### 3. Revenue Share by Product

A pie chart shows the percentage contribution of each product to total revenue.

### 4. Quantity Sold by Product

A bar chart compares the number of units sold for different products.

### 5. Quantity and Revenue Correlation

A heatmap is used to visualize the correlation between quantity sold and revenue.

## 💡 Business Insights

The analysis can provide insights such as:

* Which product generates the highest revenue.
* Which product has the highest sales volume.
* Which product generates the lowest revenue.
* Which month records the highest sales.
* Which month records the lowest sales.
* How different products contribute to total revenue.
* Whether quantity sold and revenue have a strong relationship.

These insights can support business decisions related to inventory management, product promotion, marketing strategies, and sales planning.

## ▶️ How to Run the Project

### 1. Clone or download the project

Open the project folder in VS Code.

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Make sure the dataset is available

Place the dataset here:

```text
data/raw/sales_dataset.csv
```

### 4. Run the main program

```bash
python main.py
```

### 5. Open the Jupyter Notebook

Open:

```text
notebooks/Sales_EDA.ipynb
```

Run the notebook cells to view the complete analysis, visualizations, and business insights.
